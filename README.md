# Rounds landing page

Static, no build step. Edit `index.html`, `assets/css/site.css`, `assets/js/app.js`, push `main` to redeploy (GitHub Pages).
The hero round builder is real JS (Americano circle-method schedule + leaderboard).
Early-access form posts to formsubmit.co and redirects back with `?joined=1`.
